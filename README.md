# SpendWise — Student Expense Tracker

A polished, responsive second-year web project.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or a mobile browser.
3. No server or installation is required.
4. Data is saved in browser LocalStorage.

## Included UI
- Dashboard
- Expense history with search/filter
- Add/delete expenses
- Monthly budget planner
- Category budget UI
- Spending analytics with charts
- Monthly comparison
- Smart insights
- CSV export
- Light / dark / system theme
- Responsive mobile sidebar and layouts

## Technologies
HTML5, CSS3, Vanilla JavaScript, Canvas API, LocalStorage.

**SpendWise: A Responsive Student Expense Tracking and Budget Management Web Application**
